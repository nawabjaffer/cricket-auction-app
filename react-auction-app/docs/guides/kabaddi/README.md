# Kabaddi Guide

Kabaddi uses the shared tournament setup with kabaddi-specific raider and defender roles and scoring controls. Enable Kabaddi for the tenant before opening its scorer.

## Set up

1. In Admin, select Kabaddi as the sport or enable it for the tournament.
2. Verify team rosters and role assignments, especially raiders and defenders.
3. Open Kabaddi scorer admin and create or select the fixture.
4. Confirm the teams, match period, venue, and match status.
5. Test the live display or OBS overlay before the match begins.

## During a match

Use the scorer's raid and event controls to record the result of each raid and any supported bonus, tackle, all-out, substitution, or penalty event. Verify the team in possession and the players involved before saving. After a correction, check both team totals and player statistics before resuming.

## Finish and troubleshoot

Review the score, raid/event history, and player attribution before marking the match complete. If the scorer is unavailable, check that Kabaddi is enabled for the tenant. If a display is stale, confirm the overlay and scorer are connected to the same fixture.
