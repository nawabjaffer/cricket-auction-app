# Cricket Scoring Guide

Cricket scoring is available from the tournament's scoring admin, live scorer, and OBS tools. Use the links under **Admin → Match Type** or **Admin → Streaming** so the scorer opens in the correct tournament context.

## Prepare a match

1. In scoring admin, create or select the match and verify its persistent match number, teams, format, date, and venue.
2. Set the toss result and batting order, then select the playing squad and opening batter and bowler.
3. Confirm overs, innings rules, target (if chasing), and any configured match-specific rules.
4. Open the public scoreboard in a second browser and check that the intended match appears.
5. If broadcasting, confirm OBS is connected and the score overlays show the same match.

## Record the innings

Record each delivery using the scorer's controls: runs, extras, wicket type and batter, and any strike change. Review the over total and strike before advancing. The scorecard and match summary update from the recorded events.

Use the correction/review controls when an event was entered incorrectly. Pause input, select the specific event, apply the correction, then verify the total, batter and bowler figures, wickets, and over state before continuing.

## Breaks and interruptions

- Use the interruption controls for a delay or postponement. Scoring pauses while the match is interrupted.
- Resume the same match when play restarts; do not create a replacement match just to continue scoring.
- Mark a match abandoned only when play is officially ended. Abandonment is terminal and should not be used for a temporary delay.
- At an innings break, verify the completed innings and target before starting the next innings.

## Finish and verify

Complete the match only after confirming the final result. Review both innings, wickets, extras, player figures, and the result on the public scoreboard. A completed match should not be reopened to repair ordinary entry mistakes; use the available correction workflow.
