# Auction Guide

Use this workflow to run a live auction from the main auction screen.

## Before the event

1. Open **Admin** and confirm the tournament name, sport, currency, teams, player pool, purse, and bidding rules.
2. Check that each team has the intended budget and that player base prices and categories are correct.
3. Open the auction screen on the display used by the auctioneer. Keep the admin screen available on a separate device if possible.
4. Ask team representatives to open the mobile bidding page using the tournament's **Connect to Team** link or the displayed QR code. Give each representative their team's credentials privately.
5. Test one bid with the representatives before starting. Undo or reset the test before the official auction begins.

## Run the auction

1. Select the next player with **N** or choose a player from the jump-to-player control.
2. Announce the player and invite bids. A team can bid from its assigned mobile session or the auctioneer can select the eligible team.
3. Confirm the team and amount before marking a player sold. The app checks the configured purse, roster, base-price, and increment rules.
4. Mark an unsold player with **U**. Use the unsold list or round controls to bring eligible players back later.
5. Use the on-screen undo action or **Z** to correct a recent action. Verify the player and team before continuing.

## Useful keyboard controls

- `N`: Select the next player.
- `F`: Open player jump/search.
- `1` to `8`: Select the corresponding eligible team.
- `S`: Mark the current player sold; `U`: mark unsold.
- `Z`: Undo/decrement the recent action.
- `Q` / `W`: Adjust the bid multiplier.
- `Escape`: Close the current overlay.

Shortcuts can vary by screen and are suppressed while typing in inputs. Use **Help → Shortcuts** for the active screen's list.

## After the auction

Review sold and unsold lists, check team budgets and roster counts, and export results from **Admin → Export data**. Do not reset auction progress until the results have been exported and verified.

## If something goes wrong

- If mobile bids stop updating, check the representative's team login and connection status before reloading the auction display.
- If a bid is rejected, read the on-screen rule explanation and check that team's remaining purse and roster limits in Admin.
- If the wrong player or team was selected, pause the auction and correct the last action before accepting another bid.
