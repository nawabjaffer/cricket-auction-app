# Football Guide

Football tools share the tournament's team and player setup while using football-specific roles and scoring controls. Enable Football for the tenant before opening its scorer.

## Set up

1. In Admin, select Football as the sport or enable it for the tournament.
2. Verify teams, player names, positions, and available football-specific stats.
3. Open the Football scorer admin route for the tournament and create or select the fixture.
4. Confirm both teams, match period, venue, and match status before starting.
5. Test the public/OBS display if it will be used.

## During a match

Use the football scorer's event controls to record goals, cards, substitutions, and other supported match events. Confirm the team and player before saving an event. Check the score and match clock after corrections. Pause updates during official interruptions and set the final status only after the match is concluded.

## Finish and troubleshoot

Review the event timeline, score, and player attribution before marking the fixture complete. If Football is not available, check tenant sport access and feature settings. For display issues, verify the overlay and scorer use the same tournament and fixture.
